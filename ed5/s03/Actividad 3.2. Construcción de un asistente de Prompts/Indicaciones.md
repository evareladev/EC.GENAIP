## Actividad 3.2 — Asistente de Prompts (Proyecto de Claude)

| Atributo | Detalle |
|-----------|----------|
| **Prioridad** | Imprescindible |
| **Duración** | 30–45 minutos |
| **Tipo** | Caso guiado por el instructor + práctica individual |
| **Cuentas** | Individual (gratuita basta) o por equipo Pro |
| **Entregable** | Un Proyecto "Asistente de Prompts" propio + 1 prompt refinado |

### Objetivo

Permitir que participantes con perfiles no técnicos puedan construir prompts de alta calidad sin necesidad de dominar explícitamente estructuras como **ROL – CONTEXTO – OBJETIVO – FORMATO**.

La actividad busca demostrar que los usuarios pueden describir una necesidad de negocio en lenguaje cotidiano y utilizar un Proyecto especializado de Claude para transformar automáticamente esa descripción en un prompt profesional, reutilizable y más efectivo.

### ¿Por qué importa?

Uno de los principales obstáculos para adoptar IA generativa en entornos corporativos es la percepción de que se requiere experiencia técnica para escribir buenos prompts.

Esta actividad elimina esa barrera al mostrar una metodología práctica donde:

- El usuario describe una tarea como lo haría con un compañero de trabajo.
- Claude organiza la información automáticamente.
- El participante obtiene un prompt estructurado listo para usar.
- Se fomenta la iteración y mejora continua de instrucciones.

## Práctica individual

### Paso 1. Identificar una tarea real

Cada participante debe pensar en una actividad habitual de su trabajo.

Ejemplos:

- Redacción de correos.
- Elaboración de resúmenes.
- Comparación de documentos.
- Análisis de información tabular.
- Elaboración de reportes.
- Atención de solicitudes.

### Paso 2. Describir la tarea

Ingresar la descripción en lenguaje cotidiano al Proyecto.

Ejemplo:

> Necesito comparar varias solicitudes de liquidación y generar un resumen de diferencias importantes para mi supervisor.

### Paso 3. Refinar el resultado

Solicitar una mejora utilizando instrucciones breves como:

- Más conciso.
- Más formal.
- En formato de tabla.
- Orientado a gerencia.
- En formato de lista de verificación.
- Con recomendaciones accionables.

### Paso 4. Seleccionar la mejor versión

Guardar el prompt final generado.


---

## Resultado esperado

Cada participante deberá entregar:

1. Su Proyecto "Asistente de Prompts" configurado.
2. Una descripción original de una tarea de trabajo.
3. El prompt generado por el Proyecto.
4. Una versión refinada mediante iteración.

---

## Criterios de éxito

La actividad se considera completada cuando el participante:

- Comprende el valor de estructurar instrucciones.
- Utiliza lenguaje natural para describir una tarea.
- Obtiene un prompt claramente organizado.
- Realiza al menos una iteración de mejora.
- Identifica una aplicación concreta para su entorno laboral.

---

## Recomendaciones para el facilitador

- Enfatizar que el objetivo no es memorizar estructuras de prompts.
- Mostrar ejemplos reales de mejora entre versiones.
- Favorecer casos relacionados con el trabajo cotidiano de los participantes.
- Resaltar que los Proyectos permiten reutilizar conocimiento y estandarizar buenas prácticas dentro de los equipos.
- Invitar a los participantes a conservar el Proyecto para futuras tareas laborales.

### 2. Contenido Textual
# ¿Qué es un Prompt?

> "Es una petición en lenguaje natural que se envía a un modelo de lenguaje para obtener una respuesta"
> — **Google**

> "Información, frases o preguntas que se introducen en una herramienta de IA generativa para que el modelo analice la información y genere una respuesta basada en los patrones aprendidos durante su entrenamiento"
> — **Harvard University**

**La calidad del respuesta depende de la calidad del solicitud.**

**Ejemplos poco efectivos:**
- 'Hazme un resumen.'
- 'Escribe algo sobre liderazgo.'
- 'Ayúdame con mi correo.'

**Ejemplos efectivos:**
- 'Resume este documento en 5 puntos clave, en lenguaje ejecutivo, para presentar a la junta directiva en menos de 200 palabras.'
- 'Redacta un párrafo introductorio para un taller de liderazgo dirigido a gerentes de operaciones con 10+ años de experiencia. Tono: motivador pero práctico.'
- 'Revisa este correo y sugiere cómo hacerlo más directo y profesional. Conserva el mensaje central pero elimina el relleno innecesario.'

### 3. Tablas
No aplica.

### 6. Estructura sugerida de un Prompt efectivo

| Componente | Descripción y ejemplo |
|---|---|
| Rol | Define quién debe ser el modelo en esta interacción. Ejemplo: 'Actúa como un especialista en comunicación interna corporativa.' |
| Contexto | Proporciona la información de fondo necesaria para que la respuesta sea relevante. Ejemplo: 'Estoy preparando una comunicación para empleados sobre un cambio en el proceso de solicitudes de vacaciones.' |
| Objetivo | Indica qué quieres obtener de manera específica. Ejemplo: 'Necesito un correo claro, en español, que explique el cambio y sus beneficios.' |
| Formato | Especifica cómo debe presentarse la respuesta. Ejemplo: 'Máximo 150 palabras. Sin tecnicismos. Con un asunto sugerido para el correo.' |

- **Título:** Técnicas de Prompting: encadenamiento (Chain-of-Thought)
- **Tipo:** Contenido

### 2. Contenido Textual
### Técnicas de Prompting: encadenamiento

Le pedimos al modelo que razone paso a paso antes de llegar a una conclusión. Esto reduce errores en tareas que requieren lógica o análisis. Útil en:
- Análisis de problemas complejos con múltiples variables
- Decisiones que requieren considerar pros y contras
- Revisión de documentos o argumentos.

> "Antes de responder, analiza el problema paso a paso. Primero identifica los factores relevantes, luego evalúa cada uno, y finalmente proporciona tu recomendación."

**Referencia (cita académica):**
Wei, J., Wang, X., Schuurmans, D., Bosma, M., Xia, F., Chi, E., ... & Zhou, D. (2022). Chain-of-thought prompting elicits reasoning in large language models. *Advances in neural information processing systems*, 35, 24824-24837.

Estilo flat design, colores cálidos (naranja, marrón). Ubicada en la esquina inferior derecha del slide, acompaña visualmente el globo de diálogo con la cita del prompt de ejemplo.

### 8. Iconos y Elementos Visuales

2. **Apariencia Visual** — Se almacenan las fuentes, tamaños y estilos de texto utilizados en el documento.
3. **Contenido Visual** — Las imágenes y gráficos se incluyen y se pueden extraer del documento.
4. **Estética del Documento** — Los elementos de diseño, formato y estilo se conservan.

**Fila inferior (pasos 5-8):**
5. **Localización Precisa** — Cada palabra tiene coordenadas exactas dentro del documento.
6. **Elementos Repetitivos** — La información en la parte superior e inferior de cada página se registra (encabezados, pies de página, numeración, etc.).
7. **Datos Estructurados** — Las tablas se almacenan y pueden requerir reconstrucción para ser interpretadas correctamente.
8. **Información del Documento** — Los metadatos como autor, fechas y versión del documento se almacenan junto al contenido.

Cada paso tiene un ícono representativo: pilas de páginas, letras "T" con control deslizante, imagen con onda, paleta de diseño, lupa sobre texto, ventana con barras repetidas, base de datos/tablas, y documento con imagen.

### 10. Observaciones

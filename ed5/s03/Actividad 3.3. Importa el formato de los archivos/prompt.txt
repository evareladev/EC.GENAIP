Dispones de dos archivos que contienen exactamente el mismo contenido:

- **Archivo A:** Presentación en formato **PDF** (documento original).
- **Archivo B:** Presentación en formato **Markdown (.md)** (extracción estructurada del PDF).

## Objetivos
1. Estimar el consumo aproximado de tokens requerido para procesar cada archivo de forma independiente.
2. Comparar la eficiencia de ambos formatos para un modelo de lenguaje.
3. Explicar las diferencias observadas.

# Generación del resumen

Genera un resumen de aproximadamente **1,000 palabras**.

El resumen debe:

- Integrar el contenido de ambos archivos.
- Utilizar el Markdown como fuente principal.
- Consultar el PDF únicamente cuando aporte información visual adicional.
- Agrupar conceptos relacionados.
- No resumir diapositiva por diapositiva.
- Mantener únicamente la información conceptual.
- Omitir instrucciones logísticas, temporizadores y contenido administrativo que no aporte al aprendizaje.

Organiza el resultado utilizando la siguiente estructura:

1. Introducción
2. Construcción de prompts efectivos
3. Técnicas de Prompt Engineering
4. Uso de Proyectos en Claude
5. Automatización mediante Proyectos
6. Caso práctico de automatización
7. Recomendaciones
8. Conclusiones

## Consideraciones

- Las cantidades de tokens pueden ser aproximadas; no es necesario realizar un conteo exacto.
- Explica las estimaciones utilizadas cuando sea pertinente.
- Si el modelo no puede conocer el número exacto de tokens, proporciona una estimación razonable basada en el contenido procesado.
- Prioriza la claridad de la comparación sobre la precisión absoluta del conteo.
